# Project Structure

| File | Purpose |
|---|---|
| evaluate.py | Evaluates and compares both sentiment models |
| register_champion.py | Registers models and assigns Champion/Challenger aliases |
| predict_from_mlflow.py | Loads Champion from MLflow and predicts new inputs |
| requirements.txt | Lists project dependencies |
| README.md | Project overview and execution instructions |
| eval_inputs.csv | Labelled evaluation dataset |
| new_inputs.csv | Unseen prediction inputs |
| model_comparison_predictions.csv | Model comparison results |
| metrics_summary.json | Evaluation metrics |
| metric_comparison.png | Metric comparison plot |
| confusion_matrices.png | Confusion matrices |
| new_data_predictions.csv | Champion predictions |
